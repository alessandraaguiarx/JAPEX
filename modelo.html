03 · MODELO MATEMÁTICO

Da Álgebra Linear ao quantitativo de materiais

Representação matricial, sistema linear, transformação linear e combinação linear.

REPRESENTAÇÃO MATRICIAL

Modelo M = A · X

O modelo relaciona o vetor de áreas da obra à matriz de consumo dos materiais, produzindo um vetor de quantitativos.

Vetor de entrada
X = [x
y]
x = área convencional
y = área estrutural
×
Matriz de consumo
A = [5   0
0   3
0   2]
Linhas = materiais
Colunas = tipos de alvenaria
=
Vetor de saída
M = [5x
3y
2y]
Quantitativos dos materiais
M = A · X
04 · SISTEMA LINEAR

O modelo como sistema de equações

A mesma relação matricial pode ser interpretada como um sistema linear que relaciona as áreas aos quantitativos dos materiais.

5x + 0y = Argamassa X
0x + 3y = Argamassa Y
0x + 2y = Graute

06 · ESPAÇO VETORIAL E COMBINAÇÃO LINEAR

Interpretação geométrica e algébrica

Espaço vetorial

O vetor de entrada pertence a R²:

X = [ x ; y ]

O vetor de materiais pertence a R³:

M = [ 5x ; 3y ; 2y ]

Combinação linear

As colunas da matriz podem ser interpretadas como vetores associados aos tipos de alvenaria:

V₁ = [5 ; 0 ; 0]
V₂ = [0 ; 3 ; 2]
M = xV₁ + yV₂
